# Phase 3 · Brand

**Name:** birds view (always lowercase).
**Mark:** a reticle ring with a two-stroke chevron "wing" crossing it, the view from above.
**Tagline:** "See the whole board."
**Voice:** terse, calm, operator-grade. Labels are nouns, status is one word, no exclamation marks.
